This page shows results from a set of Lichess bots that are used as part of the Computer Chess Index (CCI). The goal of these bots is not only to play games, but to provide a bridge between CCI ratings and Lichess as a widely known rating system.

Since CCI is based on controlled engine matches, while Lichess ratings are generated in an online environment with different conditions, the two scales are not directly comparable. The purpose of these experiments is therefore to understand how both rating systems relate to each other.

Based on the current data, a simple linear transformation between both scales can already be approximated as Lichess ≈ CCI / 1.8225 + 987. This indicates that the data is sufficiently consistent to derive a mapping, and that using such a transformation for calibration would in principle be possible.

However, there are also several indications that this approach should be treated with caution.

For this reason, no final calibration has been applied yet. Instead, the current results are used to collect evidence, with the goal of defining a stable and well-justified calibration at a later stage.
